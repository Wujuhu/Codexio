### 实现与复用

- 日志详情复用 `DetailsLink` / `GridDetailCell` 的原生浮窗。每次展示按需创建 `NSPopover`，关闭、表格单元复用或退出窗口时取消延迟回调并释放完整浮窗及 `NSHostingController`；旧浮窗的回调不能关闭新浮窗。
- 热图月份复用已有 11 点原生字体测量，将标签位置限制在卡片宽度内；窄窗口保留两端标签并隐藏冲突的中间标签。只删除外观设置中的侧栏开关，窗口工具栏控制保留。
- 同步沿用现有局域网 ACK、云端请求及 30 秒计时器。成功确认清除暂时网络错误；存在近期有效局域网连接时，不将云端暂时中断误报成整体断网。HTTP 429/5xx 与 URLSession 暂时错误共用分类，权限和配置问题仍正常显示。
- iOS Markdown 表格使用固定列宽、按最长单元格内容增长的行高和横向滚动，列宽跟随动态字体。代码、普通文本及现有请求展示保留。
- `RequestMedia.swift` 复用增量账本与已有按请求读取的恢复路径，提取 Markdown/HTML 图片、typed image 内容、用户文件包装、内联 data URI，以及图片生成工具的结果。原始日志不改写；历史正文只恢复相关会话的有界数据，不升级全量扫描版本。
- 用户图片跟随用户消息，模型图片嵌入最终回复；同一来源与相同图片内容去重，非图片附件仍保留。旧缩略图兼容显示但不再重复列为图片附件。代码示例中的图片语法保持文本。
- 图片复用既有 envelope、SHA-256、64 KiB 分块、host/reader 鉴权，新增 `request-images-v1` 能力协商；未经协商的旧 Worker 不接收新字段。正文与图片分开同步，单张预览最长边 2048 像素、压缩字节不超过 1 MiB，手机可点开放大；动画图片采用静态预览。
- Mac 使用 ImageIO 后台降采样，独立图片缓存有界；手机最多两个并行图片请求，压缩缓存不超过 8 MiB / 16 张，显示时按屏幕尺寸后台解码。关闭同步或更换设备会释放相应请求和缓存。缓存淘汰后的原图可按所属请求重新准备；远程图片暂时失败复用现有计时器重试，不增加采集器或定时器。
- 本地路径、可访问 HTTP(S)、原始图片内容可生成预览；无法解析的 sandbox/API 图片标识或已删除的源文件明确显示不可用，不伪造图片。
- 增量游标兼容旧版纯文本指纹，升级途中两种用户消息表示仍可正常配对；同一次请求的多次图片工具输出按来源累积去重，保留现有数量上限。成功上传的图片引用集合单独记录，引用移除后恢复时能够补传云端已删除的图片字节。
- 云端新增 `0003_request_images.sql`：独立图片表、不可续期的原始生命周期、内容到期队列与索引。图片按原始创建时间保留三天；消息正文按请求开始/完成时间保留七天，最近记录及当前任务中的用户文本按记录年龄清理；统计汇总保留。
- 读取立即拒绝过期图片/正文，后台每 15 分钟按索引分批实际删除图片、过期正文及旧摘要。调度延迟、积压或失败会推迟物理清理，不把定时任务间隔描述为精确秒级删除保证。重复同步和进程重启不延长同一云端图片的到期时间。

### 已有实测依据

2026-10-01 使用同一份隔离 SQLite（4,513 条调用、397 条请求）、2× 显示、1100 × 820 点后台可见窗口，在不扫描、不联网、不改真实配置的条件下，连续打开 12 个不同详情（间隔 0.18 秒）。对照诊断副本释放关闭浮窗后：

| 场景 | 原实现 | 释放完整浮窗的诊断副本 |
| --- | ---: | ---: |
| 基础物理占用 | 110.4 MiB | 110.7 MiB |
| 连续打开后的物理占用 | 201.1 MiB | 127.8 MiB |
| 关闭并静置 | 200.8 MiB | 123.0 MiB |

这是此前根因定位时的同条件实验，不是本次新增图片功能后的安装版整体内存承诺。正式修复保留轻量行协调器，关闭时丢弃整份浮窗及其绘制窗口；只清空 content controller 无法完全释放图形表面。证据在 `build/checks/memory-detail-20261001/findings.json`。原始 JSON 清理实验释放约 6.31 MiB 堆对象但没有观察到物理占用下降，未为此改写账本缓存。
