# Windows v0.3.4：Wails / Go 重构

用户已于 2026-09-30 明确选择 Wails + Go，要求完成 Windows 重构及前述功能修复。本设计替代比较阶段的 Avalonia 架构建议；功能基线继续使用 `2026-09-30-windows-v0.3.4-design.md` 的功能矩阵，交付目录以用户最新 AGENTS.md 为准。

## 已选方案

- Wails v3 固定 `v3.0.0-beta.26`：支持独立主窗口、悬浮窗及托盘；该版本仍为 Beta，不在构建时追随 latest。
- Go 业务层，TypeScript/Svelte 界面，SQLite 使用纯 Go 驱动，Windows 构建使用现有 Go/Node，不安装完整 Visual Studio、.NET 或 Rust/C++ SDK。
- 一个主应用宿主拥有采集、额度、更新、上游转发与手机只读同步；退出回收全部自有服务，关闭主窗口可继续托盘运行。
- Python 实现只保留为规则和迁移参考，新 EXE 不捆绑 Python/PySide。
- 开发交付 `build/dev/windows/Codexio.exe` 和统一 `latest.json`。暂存 `build/staging/windows`、依赖缓存 `build/cache`、核对结果 `build/checks/v0.3.4`。保留 Mac/iOS 清单字段，当前不推送、不发布、不触发 CI。
- Windows 版本为 0.3.4；Mac/iOS 的代码、版本与构建号保持各自原状态。用户当前运行的 0.3.3 不由开发过程结束、启动或重启。

## 数据和性能

沿用 `usage_records`、`usage_turns`、`usage_agent_links` 等原始账本及现有派生表。保护原始记录身份、跨来源去重、别名/续接/子代理归属、运行/中断状态、价格规则、缺失计量和未知费用。现有目录、文件、WAL 变化检测和追加游标迁移到 Go；没有相关变化不重读、不计价、不聚合、不发布全局界面状态。

SQLite 的查询、JSON 解码、历史汇总、图表和报告计算都在 Go 后台执行。前端只接收有界分页和展示快照；详情按需读取，查询过期结果不能覆盖新筛选。缓存依赖账本 generation、实际价格、来源、账户、筛选、时区及必要时间边界，容量有界。

继承现有 Codex Standard 基础价格和独立 Fast/长上下文倍率，不新增未经核对的价格。实际调用 Token/已知费用与用户请求计数分别计算，不拿调用数替代请求数。

## 自动审批审查修复

识别真实 `source.subagent.other=guardian`，保留父聊天、父轮次和原始来源；明确 `codex-auto-review` 调用可作分类回退，正文/标题字样不能单独分类。使用 `automatic_approval_review`。

只有明确父轮次、显式调用关系或可核对的继承边界唯一确定主请求时合并；仅父聊天、时间相邻或相同摘要不构成证据。合并后在主请求组成中保留审查，不替换用户正文/主模型/最终回复。不能关联时显示“自动审批审查”。两种情况均不新增用户请求数，也不成为最近用户任务；所有实际去重调用计量保留，未知价格显示未定价或部分定价。

概览、日志页脚、趋势、活动、模型贡献、日报/周报/月报、托盘/悬浮窗和手机同步共用这一个分类口径。上下文压缩继续单独分类且不新增用户请求数。

## 功能承接

保留六页：概览、日志、用量、订阅、定价、设置；保留日期/模型/速度/状态/搜索筛选、有界分页、可调列宽、请求详情与原文/最终回复、图表/热图悬停、真实聊天名、额度/重置券及确认行为、只读官方报告、周期观测估值、模型贡献、三套猫咪日报/周报/月报与 PNG 分享、主题/系统语言/图标/字标、托盘/悬浮窗/停靠和用户偏好。

自动更新保留检查后更新/稍后、实际下载进度、固定仓库 URL/大小/SHA-256/EXE 头校验、正常退出后原位替换、启动确认和失败回滚；文件占用时不杀进程、不产生交付目录的多份 EXE。

上游检测仍默认关闭，保留官方 provider/认证，仅在用户开启功能时管理本机转发和配置；恢复配置不覆盖用户其他配置。主应用退出停止转发，不增加常驻保活服务。手机同步承接既有 TLS/WebSocket/Bonjour、配对/撤销、DPAPI 凭证、摘要与按需详情协议；不增加远控，不部署云端。

品牌与视觉继承当前源文件和最新 AGENTS：黑白猫耳 C、最终 wordmark、现有浅/深色与数据色。比较阶段 PRODUCT 中过期品牌和旧布局不能覆盖这份明确要求。主界面和单个报告只在实际需要时查看一次截图，不做矩阵或反复设计变体。

## 验证

继续使用隔离模拟数据下三个固定冒烟事项：启动、基本数据显示、主窗口关闭重开。迁移该入口，不增加维护性测试套件、pytest 或测试项。编译/类型检查、版本、EXE 完整性、大小与哈希属于构建/交付验证。已发现的 Guardian 归属与计数问题可做一次性针对性核对；真实应用/配置/客户端不作为开发冒烟对象。

真实账户网络、手机配对、更新替换或 Linux 桌面没有相同条件验证时明确报告边界；不声明内存最低、全部卡顿消失或节能倍数。
