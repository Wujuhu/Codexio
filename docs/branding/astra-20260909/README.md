# Codexio 名称与 Logo 提案

设计模型：**GPT-6 Astra**。日期：2026-09-09。交付状态：四套待选创意，未替换应用名称、Logo 或版本。

推荐 **余度 / Yudu**。两个汉字直接传达“还有多少可用、使用是否有度”，相向量规在任务栏尺寸仍能辨认，适合克制的分析工作台。英文使用拼音式品牌名，不强行堆入 AI、Token 或 Quota。

| 方案 | 名称与符号含义 | 取舍 |
|---|---|---|
| 余白 / Margin | 实体中保留向外开放的负空间；余量不是空缺，而是下一次工作的空间。暖棕色。 | 气质安静，产品类别联想较弱；方形开口也可能读作字母 C。 |
| 余度 / Yudu | 两只相向、错位的量规，以开放空间表达测量与剩余。灰调青绿。 | 产品含义最直接，轮廓偏理性；需要用比例和留白传达温度。 |
| 刻序 / Cadra | 内外错相的两道弧线，表达短时与周窗口同时运转。灰调紫色。 | 时间意味最强；16 px 时弧间空隙较紧密，辨识不及余度，且需要文案补足用量定位。 |
| 澄量 / Clario | 对向透镜间的一道清晰通道，表达从日志与消耗中读出可靠信息。烟蓝色。 | 最柔和，但可能被理解为阅读、观察工具，独特性需要名称共同建立。 |

名称及英文展示名均为创意提案，未进行产品名、商标或域名查重。金额口径保持产品事实：API 等价费用，不是订阅实际账单。

## 文件与使用

- `brand-options.png`：1600 × 1120，四套方案 2×2 对比图，包含实际 16 / 24 / 32 / 64 px 图标与深浅底。
- `index.html`：本地直接打开；背景按钮切换深浅色，尺寸选择框切换 16 / 24 / 32 / 64 px，提供单色 SVG 下载。无第三方脚本、网络字体或服务依赖。
- `margin-*.svg`、`yudu-*.svg`、`cadra-*.svg`、`clario-*.svg`：每套各有 `mono`（currentColor）、`light`（浅底）、`dark`（深底）三版，共 12 个 SVG。透明画布，24 × 24 viewBox，无嵌入位图、渐变或外部依赖。

单色版建议作为 inline SVG 使用，由父元素 `color` 着色。通过 `<img>` 引用时，外层 CSS 的 `color` 不会自动进入 SVG 文档；此时使用预置浅底或深底文件。交付的是独立标识，不包含系统 ICO 的多尺寸封装；选定后再做最终任务栏像素优化与封装。

解压 `brand-options.zip` 后直接打开 `index.html` 即可使用完整提案；页面的图形、样式、文案与交互均已内置，不需要额外数据文件。
