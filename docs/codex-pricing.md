# Codexio 计价规则

核对日期：2026-09-10。应用版本仍为 0.2.1。

当前金额是用户指定的换算口径：**标准 API 基础价 × Codex 条件倍率**。它用美元表达 API 基准等价值，不是实际 API 账单、ChatGPT 订阅扣款或官方 credits。价格页与所有费用展示共用 `PricingCatalog` 的换算结果。

## 基础价与规则

基础目录只接受 Standard、普通上下文的 API 单价。自动源的 Priority/Fast、Flex、长上下文价格不会参与派生。手工基础价继续优先；既有旧档位覆盖留在原配置文件中，不再用于换算。

| 模型 | Fast | 输入超过 272,000 Token 时 |
|---|---:|---|
| GPT-6 Astra | ×2.5 | 不增加长文倍率 |
| GPT-5.6 Sol / Terra / Luna | ×2.5 | 输入、缓存读取 ×2；输出 ×1.5 |
| GPT-5.5 | ×2.5 | 输入、缓存读取 ×2；输出 ×1.5 |
| GPT-5.4 | ×2 | 输入、缓存读取 ×2；输出 ×1.5 |

Fast 与长文倍率叠加一次。恰好 272,000 输入仍使用普通档。阈值按每次调用的完整输入量判断，包含缓存部分；整轮用户请求的费用是调用费用之和，不用整轮累计输入再次判定长文档。

没有明确 Codex 加速规则的模型仅提供 Standard 换算，不从 API Priority 价格反推倍率。缺失档位采用 Standard 并保留“参考估计”状态；聚合旧计量记录继续保留不能证明单次上下文的说明。

## Token 计数与缓存创建

记 I 为输入总量，C 为缓存读取，W 为缓存创建，O 为输出：

```text
普通输入 = I - C - W
换算费用 = [(I-C-W) × 输入换算价
           + C × 缓存读取换算价
           + W × 缓存创建换算价
           + O × 输出换算价] / 1,000,000
```

Codex 换算行中的缓存创建单价等于普通输入单价，因此上式也等于 `(I-C) × 输入价 + C × 缓存读取价 + O × 输出价` 后除以一百万。没有额外写入溢价，也不会把首次输入当成免费。API 基准行仍保留原始 API 缓存创建价格供参考。推理 Token 属于输出，不重复收费。

例如 300,000 输入、80,000 缓存读取、10,000 缓存创建、2,000 输出，在当前基础价下：

- Astra Fast：输入／创建 25、缓存读取 2.5、输出 125，每次调用 **$5.95**。
- GPT-5.6 Sol 长文 Fast：输入／创建 20、缓存读取 2、输出 75，每次调用 **$4.71**。

## 展示与历史重算

一张表中，每个模型先显示 API 基准，再显示各适用换算条件。所有行均可选择模型，编辑入口始终修改该模型的基础价。搜索与更新按模型和条件保存选择，不会因行号变化而改错模型。

基础价和规则纳入价格版本。版本变化会触发 SQLite 展示索引的原子重建，重算调用、请求汇总、模型组成、概览、趋势、悬浮摘要和周额度估值。原始计量记录不变；缺价保持未定价，不填充零费用。
