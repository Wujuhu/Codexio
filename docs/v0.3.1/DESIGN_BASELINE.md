## 原生实现必须保持的细节

- 主窗口的字体、留白、数字层级、全宽日志和逐张重置列表按当前稿实施。后续若发现实现限制，先修正对应细节，不能顺手推翻整体设计。
- 静态 HTML 中的方框、圆形等文字图标是位置占位。Mac 使用同一套系统符号替代，统一视觉尺寸、线重与对齐，不把占位字符作为成品图标。
- 菜单栏的玻璃背景与窗口控件由原生系统材质和控件实现。静态图只能表达分组、色调与比例，不能证明真实背景透光、明暗切换和显示器缩放下已与参考图逐像素一致。
- 中英文使用同一套布局原则和数据口径。日期、时间、复数和持续时长由本地化格式化处理；示例文字与数字不作为成品默认值。
- 新额度小组件以原图作直接对照，不恢复已撤销的自造样式。当前没有用一组低保真替代图来宣称组件视觉已经完成；原生落地仍须遵守这些原图和已记录的数据替换规则。
