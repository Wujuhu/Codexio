# v0.3.1 macOS 原生重构总规划

> **实施状态更新：2026-09-26 用户已授权开始开发 v0.3.1。以下设计阶段记录保留为背景；编码前置条件已满足，当前进度见 [IMPLEMENTATION.md](IMPLEMENTATION.md)。**
> 状态：**设计中，尚未获准修改程序代码**。目标版本为 v0.3.1；当前仓库程序版本仍是 `0.2.10`。用户已明确选择**当前新版 Codex**作为主界面参照，并否定了先前自行改良的泛化卡片草图。下方参考图和界面映射是本轮设计的依据；只有用户审阅完整视觉稿并明确说可以开始实现，才进入 Swift 代码阶段。

## 1. 本轮已确定的要求

1. **整个 Mac App 用 Swift 重构**：SwiftUI 构建主要界面，AppKit 承担适合它的原生窗口、菜单栏和生命周期。完成后 Mac 包不依赖 Python、PySide6、Qt 或 PyInstaller；Windows 端仍保持现有实现。
2. **主界面以当前新版 Codex 为直接视觉基准**：沿用它的窗口外壳、标题栏、侧栏、导航行、内容留白、选中和控件节奏。Claude Mac 客户端用于数据详情、设置、文字层级与弹窗的直接参照。保留 Codexio 的六页功能，但不再为了区别而自行发明另一套卡片语言。
3. **菜单栏保留已认可的圆角分组，材质改为 Liquid Glass**：分组和细密进度条沿用 Nowdex #6，玻璃色调和透光参考新增图 1／3／4。额度卡标题固定为 **Codex**；菜单栏状态项默认显示原有单色 App 标记与**周额度剩余百分比**（如 23%），点击前即可查看。macOS 26 使用原生玻璃，macOS 15 保留系统材质兼容。
4. **新增额度专用最小桌面小组件**：以 Nowdex 附件 #1–#5 的实际样式为直接目标，提供单额度、双额度和刻度条三个独立注册的小组件，每个固定样式。原先自行设计的“Codexio X 标头 + 普通进度卡”方案已撤销。
5. **现有请求小组件的小、中、大三种 UI 完全不变**：不重排、不换色、不调整字号、图形或内容层级。Swift 迁移时只做必要的实现兼容与身份保留；出现视觉差异即视为回归问题。
6. **减少多余悬浮提示，保留日志专用详情预览**：日志表格最末列为“详情 / Details”，鼠标停留显示可滚动、可复制的浮层，移开链接与浮层后关闭，不占固定页面宽度。其他显而易见或重复的悬浮提示和注释式文案可以删除；错误、过期、费用估值等重要事实仍清楚显示。早期 Windows MVP `PLAN.md` 不再指导本次 Mac 设计。
7. **订阅页逐次列出可用重置**：Mac 与 Windows 都在“主动重置”中显示每张重置及其截止时间，**每一行末尾各有“使用重置 / Use reset”按钮**，由用户选择。确认后把该行的 `creditId` 交给 Codex App Server 的 `account/rateLimitResetCredit/consume`；成功后重新读取额度和逐次列表。总次数只是摘要，不能代替逐行内容；此处的重置次数不是付费余额。
8. **两端删除 SSH 来源功能**：Mac 与 Windows 均停止 SSH 采集，设置页移除“本机／SSH 列表”、来源增删改和多来源历史归属入口；保留自动发现本机 Codex 的路径设置和本地重扫。已索引的历史记录不因升级被删除；“上游检测”是另一项功能，继续保留。
9. **快速完成，测试保持最小**：只沿用现有隔离模拟数据冒烟的三件事：能启动、基本数据显示正常、主窗口能关闭并重新打开。无新增测试文件、专项脚本、全量回归或截图矩阵。签名、Widget 版本、ZIP 和哈希仍按交付规则核验。
10. **中英文界面覆盖 Mac 和 Windows**：默认按用户设备的界面语言选择简体中文或英文；两端导航、六页、设置、弹窗、菜单、状态及小组件文字使用同一套术语。Mac 的中文和英文均使用 macOS 默认系统字体；Windows 使用 Windows 系统界面字体。语言规范见 [LOCALIZATION.md](LOCALIZATION.md)。
11. **先完成所有设计，再改代码**：页面、菜单栏、新额度小组件、弹窗和关键状态需要完整设计稿。用户不满意就继续改设计；设计未被明确认可之前不进行任何程序实现。
12. **侧栏采用旧版 Codexio 图标类型**：概览四宫格、日志列表、用量折线、订阅卡片、定价标签、设置滑杆。静态稿直接使用现有路径，避免几个形似方框的占位字符。
13. **图 5 版式、完全本地统计**：用量活动页增加累计 Token、单日峰值、最长聊天时长、当前／最长连续天数；全年热力图下放 Fast 和最常用推理强度占比。所有这些数据只计算本机记录，**不读取账户统计接口**，避免把其他设备使用混入。
14. **图 6 套餐用量历史**：订阅页按原图显示服务端返回的本轮周周期、已用限额百分比和逐模型贡献；保留统计截至时间与近似／不完整状态。每张重置的独立使用按钮继续保留。
15. **图 7 聊天用量排行**：每行显示占当前周限额的比例与已用额度，展开显示模型／速度／推理强度占比。已找到官方开源后端查询合同，开发先确认账户可用性；缺失时提供明确标名的本机 Token 视图。

## 3. 每个区域由谁作视觉基准

| Codexio 区域 | 主视觉基准 | 内容如何替换 |
| --- | --- | --- |
| 原生主窗口外壳、标题栏、左侧导航、收起栏、选中行 | 当前新版 Codex | 导航项仍是概览、日志、用量、订阅、定价、设置；Codexio 名称与现有图标保留 |
| 主内容的标题、分组、表格、详情浮层、设置和弹窗 | 当前新版 Codex + Claude Desktop | 使用更宽的主内容区和较小的额度数字；日志最末列悬停“详情”显示临时浮层；订阅页增加重置按钮；不添加聊天输入框或项目列表 |
| 概览和订阅中的额度表现 | Nowdex #1–#5 | 按 Codexio 的 5 小时／周窗口和真实状态替换标签与数值 |
| 原生菜单栏展开面板 | Nowdex 分组 + 新增玻璃图 #10／#12／#13 | 额度组叫 Codex；图标旁默认周剩余数字；今天和近 7 天仍是本机数据 |
| 用量活动／套餐历史／聊天排行 | 用户 ChatGPT 实图 #14／#15／#16 | 图 5 本地计算，图 6／7 服务端额度；不能混用口径 |
| 新额度专用小组件 | Nowdex #1、#2、#5 | 做三种样式、明暗两版，只含额度和刷新／重置信息 |
| 已有请求小组件小／中／大 | **当前 Codexio UI 本身** | 视觉完全不变；只迁移 Swift 宿主和数据接口 |
| 设置 → 数据源 | 当前新版 Codex + Claude Desktop | 不显示本机／SSH 来源列表和管理按钮；只保留本机 Codex 路径、本地记录维护 |
